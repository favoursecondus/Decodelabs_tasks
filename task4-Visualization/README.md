# Task 4: DecodeLabs Ecommerce Analytics Dashboard

## Project Overview

An interactive ecommerce analytics dashboard built to explore sales performance, monitor key business metrics, and turn raw order data into actionable insights.

The dashboard uses Google Sheets as its data source and Google Apps Script to power the web application. It was developed through an AI-assisted coding workflow, with iterative refinement and testing.

## Key Features

- **KPI Summary:** Monitor key sales and order performance metrics.
- **Revenue Analysis:** Explore revenue trends over time.
- **Product Performance:** Identify top-selling products and compare category performance.
- **Order Insights:** Analyse order patterns across weekdays and weekends.
- **Interactive Filters:** Explore the data using available dashboard filters.
- **Order Management:** Add, edit, and delete records through the dashboard.
- **Business Insights:** Surface useful patterns in the ecommerce data.

## Tools and Technologies

- Google Sheets
- Google Apps Script
- HTML
- CSS
- JavaScript
- AI-assisted development

## Development Approach

AI-assisted development supported code generation, implementation, and refinement. The project involved connecting the dashboard to spreadsheet data, developing interactive visualisations, and testing the application to improve its functionality.

## Business Value

The dashboard provides a central view of ecommerce performance, helping users explore revenue trends, identify strong-performing products, understand order patterns, and make more informed business decisions.
